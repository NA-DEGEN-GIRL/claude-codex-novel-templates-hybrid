# Profile: Romance (현대 로맨스)

**Status**: 현대 배경, 두 인물(또는 이상)의 관계 발전이 서사 축.

## 적용 범위

- 현대 로맨스 (사내/학원/동창)
- 계약 연애, 소꿉친구, 이웃사촌, 원수-연인
- 직장 로맨스, 의료 로맨스, 엔터테인먼트 로맨스
- **포함 안 됨**: 사극/판타지 로맨스는 wuxia/game-fantasy + 관계 중심 설정 조합

## 기본값 (override of modern)

| 필드 | 값 | 근거 |
|------|-----|-----|
| era | modern | 현대 배경 전제 |
| Hanja pipeline | OFF | 인명 한자 병기 정도만 선택 |
| 수사 체계 | 아라비아 허용 | 현대 일반 |

| 호칭 변화 추적 | **핵심 필드** | "씨 → 오빠 → 이름" 같은 전환이 플롯 비트 |
| 기본 조연 슬롯 | 친구, 라이벌/삼각관계, 가족, 직장 동료 | |

## 톤 기본값

- 감정/관계 6 : 일상 3 : 갈등 1 (장르 표준)
- 주인공 POV: 감정 세밀 묘사, 자기 판단과 타인 해석의 간극
- 대화 비중: 전체의 50%+ 권장 (관계물 장르 특성)

## 특화 규칙: 대화 위계와 감정 온도

**호칭/어투 매트릭스 (`CLAUDE.md §8.1`)를 감정 지표로 사용**:
- 초기 ("~씨" / 존댓말): 거리감
- 중간 ("~형" / "~언니"): 친밀도 형성
- 후기 (이름 호칭 / 반말): 연인 관계
- 의도적 역전 (갈등 시 다시 존댓말): 관계 위기 신호

**Reviewer 주의**: 위계 변화는 **플롯 이벤트**이지 drift가 아니다. `relationship-log.md`의 이력과 `CLAUDE.md §8.3 어투 변화 이력`을 먼저 참조.

## 권장 Settings 변경

- `settings/03-characters.md`: "대화 대비축" 필드 강화 — 주인공 A와 상대역 B의 **감정 온도 대비**가 핵심
- `settings/01-style-guide.md §4 Show Don't Tell`: 감정 장면에서 평소보다 신체 반응/감각 세밀도 높음 (허용 이탈 유형 §0.5 참조)
- `summaries/desire-state.md`: "관계 욕망 / 불안 / 이번 화 터치 포인트" 필드 능동 활용

## Writer 힌트

- **감정 장면의 여백**: 대화 중 침묵, 시선, 호흡을 문장으로 처리. 감정 요약 금지 (P5 감정 선언 패턴).
- **1인칭 시점 가능**: 현대 로맨스는 1인칭 시점이 자연스러움. 기본 템플릿의 3인칭 전제와 차이 — `settings/01-style-guide.md §1 시점` 조정 필요.
- **갈등 페이싱**: 관계 위기 → 화해 리듬이 아크 경계와 일치하도록 plot 설계.

## Reviewer 힌트

- 대화 위계 변화는 **이벤트**로 인식. 드리프트 지적 금지 (relationship-log 확인 후).
- "P3 메타적 자기 분석"은 로맨스 내면 묘사에서 **자연스러운 장르 관습**. 정량 트리거(3회 이상 연속)만 적용.
- 감정 장면의 신체 반응 반복은 반복-checker가 **시그니처로 승격 검토** (S5 Repetition cleanup 과도 수정 금지).

## 장르 특화 주의

- **상대역의 내면**: 다중 POV 로맨스는 양쪽 시점 균형 필요. 한쪽 POV만 치우치면 "일방 짝사랑" 서사 (장르마다 가/부 다름).
- **진전 속도**: 웹소설 로맨스는 초반 3~5화 내 "끌림" 성립이 독자 잔류 기준. 너무 느린 관계 구축은 이탈 유발.
- **삼각/사각관계**: 진행 시점마다 각 인물의 우선순위 추적. `relationship-log.md` 이원 관리 (라이벌의 인식 vs 주인공의 인식).
