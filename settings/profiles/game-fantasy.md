## 시스템 창 표기 규칙

- **시스템 창 블록**: 코드블록 또는 대괄호로 감싸서 서술과 구분
  ```
  [레벨 업]
  체력 +10, 공격력 +3
  스킬 포인트 +1
  ```
  또는 `『 』` 또는 `【 】` 사용.
- **스탯 표기**: 아라비아 숫자 + 단위. `HP 450/500`, `공격력 125`.
- **주인공 내면 독백**: 스탯/수치 언급 시 정확 수치는 OK (캐릭터가 시스템 창을 본 상태).
- **시스템 외부 대화**: "몇 레벨이야?" / "한 50쯤?" — 어림 허용. 공식 시스템 창 읽기는 정확.
