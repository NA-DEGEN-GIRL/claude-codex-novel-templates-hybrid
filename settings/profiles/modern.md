# Profile: Modern (현대)

**Status**: 현대 한국 또는 가상의 현대 도시 배경. 일반/직장/학원/사회 드라마.

## 적용 범위

- 현대 한국 도시 배경 (서울/부산/가상 광역시)
- 직장, 학원, 가족, 사회 드라마
- 스릴러, 미스터리, 의학/법조 드라마도 포함 가능
- **포함 안 됨**: 판타지/SF 요소가 핵심이면 다른 profile

| 필드 | 값 | 근거 |

## 톤 기본값

- 일상/현실 6 : 긴장/갈등 3 : 유머 1 (장르별 조정)
- 주인공 POV: 현대 한국어 구어체 내면 독백 자연
- 대화: 업무/가족 상황별 경어 체계가 엄격하지만 자연스럽게 운용

## Writer/Reviewer 힌트

- Writer: "스마트폰 불빛" "테이크아웃 커피" 등 현대 감각 자연스러움. 번역투 경계는 유지.
- Reviewer: 아라비아 숫자 발견 시 플래그 금지. 단 가격 합산 장면의 정밀도 누수는 여전히 확인 (CLAUDE.md §3.2.7).
- Hanja MCP 호출은 의도적 한자 병기(법률/의학 전문용어 등)에만 제한.

## 장르 특화 주의

- 시간/장소 정확도: 실제 한국 도시/시간/제도와 맞는가. `novel-calc` MCP의 `date_calc`, `travel_estimate` 활용.
- 직업 디테일: 오피스/의료/법조 장르는 해당 분야 전문 용어/관습 정확성 요구.
- 존대/반말: 직장/가족 위계가 현대식으로 다시 매핑됨. CLAUDE.md §8.1 매트릭스 갱신 필수.
